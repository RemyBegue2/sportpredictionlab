# Risques et portes — V4.0

## Limites connues

1. Les données historiques nécessitent un abonnement The Odds API compatible.
2. Les artefacts GitHub ont une durée de conservation ; une reprise après expiration repart d’un plan frais.
3. Les campagnes de 300 ou 1 000 observations peuvent produire des artefacts volumineux.
4. Le coût par snapshot est estimé depuis la dernière preuve lorsque disponible, sinon à 10 crédits ; le coût réel reste contrôlé par le plafond d’exécution.
5. La Premier League et le marché 1N2 à T−1 h restent le seul périmètre V4.0.
6. Le workflow ne modifie jamais le champion.

## Porte stage 30 → 100

- intégrité technique acceptée ;
- zéro fuite temporelle ;
- zéro doublon ;
- couverture fournisseur ≥ 80 % ;
- matching fiable ≥ 95 % ;
- couverture consensus ≥ 70 %.

## Porte stage 100 → 300

Même porte, plus un coût par événement accepté et stable.

## Porte stage 300 → 1 000

Même porte, plus un benchmark préliminaire calculable sur plusieurs folds chronologiques.

## Porte de promotion modèle

Hors périmètre V4.0. Une campagne favorable peut seulement rendre le modèle éligible à une revue humaine.
