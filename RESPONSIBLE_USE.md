# Utilisation responsable

Sports Prediction Lab est un outil de recherche probabiliste.

Il ne se connecte pas à un compte Winamax, ne place aucun pari, ne recommande aucune taille de mise et ne promet aucun rendement.

La V3.3 peut afficher un résultat fictif normalisé à une unité. Cette valeur sert uniquement à comparer des règles de sélection sur un historique. Elle n’est pas une suggestion de bankroll.

Le système doit pouvoir conclure chaque jour :

> Aucun candidat retenu.

Le modèle football actuel est trop ancien pour une utilisation opérationnelle et le modèle tennis n’est pas calibré. Ces deux limitations déclenchent un veto dans l’application.

Évitez d’utiliser l’outil pour augmenter la fréquence de jeu, poursuivre des pertes ou fixer un objectif de gains. Le shadow mode doit rester une phase d’observation sans mise.
